# 密码更新策略公告邮件模版

> 用于正式告知用户 LDAP 密码更新策略。发送前替换 `[方括号]` 占位符。
> 建议用 donotreply 账号作为发件人，主题固定，正文为正式公告风格。

---

## 邮件元信息

| 项 | 值 |
|----|----|
| 发件人 | SMTP_FROM（donotreply 账号，见 password_expiry_notify.env） |
| 收件人 | 全体 LDAP 用户（或按 OU 分组发送） |
| 抄送 | IT 部门 ADMIN_TO |
| 主题 | 【重要通知】关于公司 LDAP 账号密码更新策略的说明 |

---

## 邮件正文模版

```
主题：【重要通知】关于公司 LDAP 账号密码更新策略的说明

各位同事：

大家好！

为保障公司信息系统与数据安全，现将公司统一身份认证（LDAP）账号的密码更新策略正式通知如下，请各位知悉并配合执行。

一、密码有效期
1. 账号密码有效期为 90 天（自最后一次修改密码之日起计算）。
2. 密码到期前 7 天，系统将开始发送到期提醒通知。
3. 密码到期后仍有 30 天宽限期；宽限期内未修改密码，账号将被锁定，需联系 IT 部门解锁。

二、密码复杂度要求
新密码需同时满足以下要求：
1. 长度不少于 8 位；
2. 包含大写字母、小写字母、数字、特殊字符四类中的至少三类；
3. 不得包含用户名或与近期使用过的密码重复。

三、修改密码的两种方式
方式一：登录 Linux 服务器修改
  通过 Exceed TurboX（ETX）登录 Linux 服务器后，在终端执行 passwd 命令，
  按提示输入当前密码和新密码即可完成修改。

方式二：自助密码修改网站
  1. 访问 https://[SELF_SERVICE_URL]/ ；
  2. 在登录页面的“目录服务”下拉框中选择“LDAP Account”；
  3. 输入您的账号和当前密码登录；
  4. 登录后按页面提示设置新密码。

四、注意事项
1. 修改密码后，请务必记住新密码；新密码将在所有关联系统（Linux 登录、
   邮件、内部系统等）中统一生效。
2. 若忘记密码或账号被锁定，请联系 IT 部门协助处理。
3. 请勿将密码告知他人，也请勿在公共电脑上勾选“记住密码”。

如有任何疑问，请联系 IT 部门：
  邮箱：[IT_EMAIL]

感谢您的理解与配合！

IT 部门
[YYYY年MM月DD日]

（本邮件由系统自动发送，请勿直接回复。）
```

---

## 使用说明

1. 发送前替换占位符：`[SELF_SERVICE_URL]`（自助网站域名）、`[IT_EMAIL]`
   （IT 邮箱）、`[YYYY年MM月DD日]`（发送日期）。
2. 若公司密码策略参数与模版不同（有效期/宽限期/复杂度），先按实际策略
   参数修改，再发送。
3. 建议在密码过期通知脚本（password_expiry_notify.py）正式启用前 1~2 周
   先发此公告，给用户留出适应时间。
